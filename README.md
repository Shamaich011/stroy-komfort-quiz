# Строй Комфорт — калькулятор ремонта и админка

- `/` — квиз (заявки сохраняются на сервере).
- `/calc` — калькулятор: помещения, выбор отделки и сантехники, схема-визуализация, смета, заявка.
- `/admin` — админка: заявки с прибылью по каждой, статусы, статистика, наценка/налог/скидка, расценки работ, каталог.

## Как считается цена

```
цена клиенту = (материалы по цене магазина + работы + подряд) × (1 + наценка) / (1 − налог)
прибыль      = цена − налог − (материалы со скидкой поставщика + работы + подряд)
```

Клиент видит только итоговые цены строк. Себестоимость, наценка, налог и скидка поставщика
видны только в админке. Расчёт идёт на сервере (`server/pricing.js`).

Стартовые цены каталога (`server/seed.js`) собраны по страницам baucenter.ru и требуют проверки:
позиции с пометкой «цена не проверена» — рыночные оценки. Цены правятся в админке.

## Запуск

```
npm install
ADMIN_PASSWORD=пароль npm start   # http://localhost:3000
npm test
```

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | пароль админки (без него при старте печатается временный) |
| `SESSION_SECRET` | ключ подписи входа в админку (без него вход сбрасывается при перезапуске) |
| `DATA_DIR` | папка базы SQLite, по умолчанию `./data`; на Railway — путь к volume |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | уведомления о новых заявках в Telegram (необязательно) |

Требуется Node.js 22.13+ (встроенный `node:sqlite`).

## Установка на VPS (Beget VPS, Ubuntu)

Домен (например `calc.sk-krd.ru`) должен указывать A-записью на IP сервера. На сервере от root:

```
curl -fsSL https://raw.githubusercontent.com/Shamaich011/stroy-komfort-quiz/claude/apartment-repair-cost-calc-yty2dt/deploy/install.sh | bash -s -- calc.sk-krd.ru
```

Скрипт ставит Node.js и Caddy (HTTPS), запускает приложение как службу и печатает пароль админки.
Повторный запуск той же команды обновляет код; заявки и пароль сохраняются.

## Перед боевым запуском

- Перенести сервер в российское облако (152-ФЗ: персональные данные граждан РФ хранятся в РФ).
- Опубликовать политику обработки персональных данных и уведомить Роскомнадзор.
- Проверить цены каталога и расценки работ.
